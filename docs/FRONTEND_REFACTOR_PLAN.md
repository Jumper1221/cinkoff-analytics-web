# FRONTEND_REFACTOR_PLAN — перевод фронта на продакшн-стек

Статус: **ПРОЕКТ** (24.09.2026). Ждёт решения Михаила: рекомендация — пункт 3.1 (Vue-миграция).
После «го» реализуется по этапам, каждый этап — самостоятельная рабочая единица, которую можно деплоить.

## 1. Зачем

Сейчас фронт — бесшовная (без-сборочная) SPA: `vue.global.prod.js` + `chart.umd.js` как вендорные файлы,
Options-API-вьюхи, шаблоны — бэктик-строки внутри `.js`. 9 вкладок, ~1120 строк, работает. Но:

- нет сборки: никаких типов, минификации при билде, код-сплиттинга, линтера, тестов;
- шаблоны в JS-строках — нет подсветки, нет проверки на этапе компиляции, ошибки ловятся только в рантайме браузера;
- Options-API масштабируется плохо: импорты из `common.js` надо вручную пробрасывать в `methods` (уже ловили «fmtMln is not a function»);
- логика (запросы, форматтеры, состояние) перемешана с разметкой в каждом файле.

Нагрузку сейчас держит PostgreSQL, а не браузер, — но «задел под функционал» это именно
тулчейн: типы + тесты + линтер + компоненты = новые фичи дешёвые, ошибки дорогие-на-этапе-написания,
а не «нашли в бою через месяц».

## 3. Решение

### 3.1 Рекомендация: **Vue 3.6+, миграция без остановки**

- существующие вьюхи переписываются по одной, сайт живёт всё время;
- часть знания (API-эндпоинты, форматы данных, бизнес-логика фильтров) переносится как есть;
- Vapor Mode — опция на потом для самых горячих таблиц (он в 3.6-RC, в базу не тащим);
- при желании Михаила «React-палец» — план тот же, но §3.3 список заменяется и +30–50% трудозатрат.

### 3.2 Целевой стек

- **Vue 3.6** (Composition API, `<script setup lang="ts">`; Options-API не тащим)
- **Vite 7+** — дев-сервер с `/api`-прокси на :8010 и прод-билд (минификация, код-сплиттинг по вьюхам)
- **TypeScript (strict)** — типы ответов API; на стыке с бэком — свои описания (не кодогенерация, еёVolume не оправдан)
- **vue-router 4** — вместо ручных `#v=`-хешей; история-режим + fallback FastAPI (все не-`/api` пути → `index.html`)
- **Pinia** — сессия/тема/тосты/состояние фильтров (Ctrl+K-поиск получает свой стор)
- **Chart.js остаётся** в первом этапе; **ECharts** — решить на этапе R2 (тепловая карта станет ис-коробки, +10+ типов виз для «задела»)
- **Vitest + @vue/test-utils** — юнит-форматтеров/сторов, компонентные смоки; headless-хром-прогоны остаются как E2E-дым
- **ESLint + Prettier** — сразу, не «когда-нибудь»

### 3.3 Если выбрать React

`react-router` / **TanStack Query** (кэш+ошибки)/ **Zustand** / Vitest — те же роли.
Разница: переписываются ВСЕ шаблоны в JSX, дальше +30–50% трудозатрат того же плана.

## 4. Этапы (каждый = работающий деплой, приоритет сверху вниз)

### R0 — каркас (0.5 вечера)
- ветка `v2` в этом репо: Vite+Vue+TS+router+Pinia+ESLint+Vitest;
- лэйаут: сайдбар/топбар/маунт-точка/модал-рут/тост-рут; тема-токены (светлая — база, тёмный тумблер сохраняем);
- `deploy-v2.sh`: `npm run build` → `dist/` → docker cp → рестарт → healthcheck;
- старый фронт продолжает работать как есть до R4.

### R1 — ядро данных + 3 вьюхи (1–2 вечера)
- типы ответов API (строгие, ручные) + `useApi`-компосабл: AbortController, ретраи, тосты ошибок, кэш-инвалидация;
- **Дашборд** (KPI, сравнение периодов, скорость), **Заказы** (таблица: сорт/пагинация/CSV/досье-модалка), **Годы**;
- критерий: паритет фич с легаси-вьюхами по чек-листу.

### R2 — остальные 6 вьюх (1–2 вечера)
Товары (ABC + карточка-модалка), Остатки (+динамика), Цены, Прогноз, Точки, Heatmap;
Ctrl+K-глобальный поиск (Overlay в лэйауте, свой стор);
решение по Chart.js→ECharts принимается здесь (по тепловой карте видно сразу).

### R3 — полировка (0.5–1 вечер)
- мобильные брейки (<640px) — паритет с текущими;
- loading-skeleton/empty-state/ошибки-тосты — всё, чего легаси не имел;
- код-сплиттинг проверен: первая загрузка < 60 КБ gzip (сейчас 54 КБ одним куском).

### R4 — переключение (0.5 вечера)
- `dist/` деплится как основной (`/`), легаси-SPA остаётся досягаемой на `/legacy/` до «ОК» Михаила, потом удаляется из контейнера;
- headless-прогон всех 9 вкладок + Ctrl+K: 0 ошибок консоли; vitest зелёный.

## 5. Приёмка каждого этапа

- headless-хром: 0 строк CONSOLE-ошибок на всех затронутых вьюхах;
- vitest: зелёный; ESLint: 0 ошибок;
- паритет фич с легаси — по письменному чек-листу вьюхи;
- деплой в бой — с показом Михаилу (правило Гейтс: push/боевой-стек — после «да»).

## 6. Риски

- Vapor Mode — RC: не используем в базе, только флаг-на-потом (стабильный VDOM-путь не трогаем).
- Первый `npm install` на этой машине: node 24 + npm 11 есть, registry доступен (проверено `npm view`); ~2 мин один раз.
- Всего-II вероятность «старый-фронт-затёрли-раньше-времени» закрывается тем, что легаси живёт до R4-«ОК».

## 7. Вне скоупа (намеренно)

Бэк-энд не трогаем (FastAPI остаётся источником JSON), SSR/SEO нет, новые аналит-фичи — только после паритета,
внешний доступ-интернет — отдельно и позже.
